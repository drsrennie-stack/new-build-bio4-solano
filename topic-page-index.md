## Button markup

Paste this next to a video. Real anchors, visible focus, 40px minimum target height,
`target="_top"` so it works inside a Kajabi iframe.

```html
<div class="topic-buttons">
  <a class="tb tb-solid" href="m4-urinary-notes.html" target="_top">Read the notes</a>
  <a class="tb" href="m4-urinary-worksheet.html" target="_top">Open the worksheet</a>
</div>

<style>
  .topic-buttons{display:flex;gap:10px;flex-wrap:wrap;margin:18px 0}
  .tb{display:inline-flex;align-items:center;min-height:40px;padding:10px 16px;
    font-family:"Plus Jakarta Sans",sans-serif;font-weight:700;font-size:.9rem;
    color:#5E201A;background:#fff;border:1.5px solid #5E201A;border-radius:6px;
    text-decoration:none}
  .tb-solid{background:#5E201A;color:#fff}
  .tb:hover{background:#5E201A;color:#fff}
  .tb-solid:hover{background:#7A2A22}
  .tb:focus-visible{outline:3px solid #5E201A;outline-offset:3px}
</style>
```

For a lab-only video, swap the notes button for the structure list:

```html
  <a class="tb tb-solid" href="module-3-structure-list.html" target="_top">Lab structure list</a>
```

Contrast: maroon-dark `#5E201A` on white is 12.37:1 either way. Both clear AAA.
