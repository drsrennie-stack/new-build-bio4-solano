Canvas setup: syllabus pages

Five Canvas pages, one announcement and one gradebook change. Each page uses the same code in all three Canvas courses.

How to add each page

  1. Pages, then + PageType the page name exactly as shown.
  2. Open the HTML editorThe </> button at the bottom right of the editor.
  3. Paste the embed codeIt is the same in all three courses. Pages with dates show both Mon/Wed and Tue/Thu.
  4. Save and publishThen add it to your Syllabus module.

Canvas removes styles and scripts from pasted HTML, so each page is embedded from your site. Change a page on the site and every Canvas course updates. The link under each frame helps students on the Canvas phone app.
