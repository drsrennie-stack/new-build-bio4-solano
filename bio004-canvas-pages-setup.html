Canvas setup: syllabus pages.

Six Canvas pages, one announcement and one gradebook change. Each page uses the same embed code in all three Canvas courses.

How to add each page

Paste once, update everywhere.

01Pages, then + PageType the page name exactly as shown.
02Open the HTML editorThe </> button at the bottom right of the editor.
03Paste the embed codeIt is the same in all three courses. No page shows section days or dates.
04Save and publishThen add it to your Syllabus module. Change a page on the site and every Canvas course updates.
