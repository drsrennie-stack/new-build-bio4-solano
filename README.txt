BIO 004 Module 4 note sheets, updated to match the lecture slides

Respiratory: 17 pages (was 6). Lower limb and lymphatic: 10 pages (was 4).

What changed
1. Structure notes pages. After each pair of boxes there is now one page per box with photos: one card per numbered
   structure, with the same lines the slide reveals (Def, Origin, Insertion, Action, Nerve, Blood supply, Borders, Clinical,
   whichever apply to that structure). Students write the name on the top line, then fill each line as the slide reveals it.
   The KEY prints every line filled in.
2. Photos are now a grayscale print version with the contrast stretched and local contrast boosted, so neighboring tissues
   separate on a black and white copier. The html and slides still use the color originals; students who want color can
   open the html and print it themselves.

Files: html (click a box to zoom on screen), PDF (print), -KEY versions of each. Keep fonts-jakarta.css and img/ with the html.
