Canvas week links

One link per week module. Each one opens the weekly schedule on that week, where the student finds their pre-work, the brain dump or TBL, the lecture and the lab. Canvas holds the link, the site holds the content, so when a date or a file changes you change it once and Canvas follows.

Set this up once

Put one button on the Canvas home page

Edit the home page, click the HTML editor button (</>), and paste this where you want it. It opens on whatever week the term is in, so it stays right all semester.

Add one item to each week module

  1. Open the week module in Canvas and click the +.
  2. Choose External URL, paste that week's link from the table below, and tick Load in a new tab.
  3. Name it the same way every week, so the module list reads down cleanly: Week 06 · Schedule and pre-work.
  4. Publish it.

Seventeen items, one pass, and then there is nothing to maintain. Nothing here is graded, so no dates or points to set.

All three sections in one shell

The links carry no section, on purpose. A student picks their class once at the top of the schedule page, the site remembers it, and every page follows that choice from then on. Until they pick, the page says so and shows Mon / Wed.

If you want to point one student at their own section, add ?sec=mw, ?sec=tr-am or ?sec=tr-eve to the end of the link.
