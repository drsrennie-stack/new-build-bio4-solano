Quick Access: Canvas embed code

Canvas strips scripts from pages, so the auto-resize used on Kajabi will not run here. These iframes use a fixed height and scroll inside the frame instead. Paste the block for each class into that Canvas course's page using the HTML editor (</> button). Each page is a dedicated copy locked to its class: no picker, no changing, exam dates already correct. Both Tuesday / Thursday classes share the same exam dates, so they use the same page.
